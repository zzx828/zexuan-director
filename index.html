内容引擎拆解

动作 / 表情型引擎：手势舞回归单条 35.7 万赞、4.6 万收藏、7.1 万分享，同时提供「动作节奏 + 可模仿 + 可转发」三重钩子；对镜颜值片多数只有 1–10 万赞，证明流量来自动作事件而非静态好看。

粉丝池（方向性推断）
  • 男性为主，约 6–7 成；18–30 岁核心，含「看她长大」的养成系老粉（中高置信）
  • 点赞收藏慷慨，但粉团率低、无带货口碑——典型「曝光型资产」而非转化型私域
  • 实际商单集中在游戏 / 文旅 / 潮玩，广告主认知已被固化为「男粉流量型甜妹」
核心判断

问题不是「粉丝差」，而是粉丝资产与高端美妆目标错配；最优先风险是幼态视觉 + 男性凝视评论区构成的品牌红线组合，先迁移画像、再谈品类升级。

90 天动作：4:4:2 双池模型——40% 去擦边化流量款保推荐池，40% 品牌款（人设 + 变美过程），20% 商单维持收入；同步做评论区置顶与控评管理。KPI 不是涨粉，是女性粉丝占比与美妆 TGI。

粉丝池（方向性推断）
  • 男女混合，女性占比显著更高：「斩男又斩女」「性取向五颜六色」类女性审美互动已出现
  • 核心观众推断为 18–28 岁审美型女性 + 18–30 岁男性（中置信）
  • 已有直播与私域导流习惯（「要链接加姐妹群」），私域电商是现实现金流
核心判断

两人中更接近美妆时尚池，但缺三样东西：稳定人格人设、干净评论区、种草证据链；最新评论已出现「你全是 AI」信任质疑，若不处理会反噬「高级感」资产。

90 天动作：把千金 / 斩女做成固定系列化 IP（统一妆造体系 + 场景 + 叙事线）；品牌形象号与好物私域号矩阵分层；用花絮 / 原相机 / 过程化内容把「真实感」做成资产。先够中高端国货美妆 / 香水，再谈大牌。

方法说明：抖音公开主页与视频页数据抓取（2026-09-08）→ 用「母题 × 期待 × 兑现」拆解内容引擎 → 评论区舆情采样推断粉丝结构 → 商务适配矩阵评估 → 输出 90 天动作。粉丝画像为方向性推断，正式投放请以星图 / 蝉妈妈 / 新抖数据为准。
